# Contributing

See [CONTRIBUTING.md](../CONTRIBUTING.md) for coding standards, PR workflow, and the one-commit-per-file convention.

Before you dig into a bug, read the [architecture on-ramp](../CONTRIBUTING.md#architecture-on-ramp-where-a-change-lands) in CONTRIBUTING.md: it maps the five layers to the `src/` files that own them, and tells you when a bug belongs in a sibling repo instead of here.
